# Tidy

Tidy is a command-line tool that cleans up messy folders without surprises.

- `tidy scan` finds duplicate and forgotten files (old downloads, installers, screenshots).
- `tidy plan` shows every move and delete it would make, before it touches anything.
- `tidy undo` puts everything back exactly as it was.

Website: https://tidy.dev — free and open source.

The video project in this folder uses Remotion (`npx remotion render src/index.ts <composition> <output>`).
Dependencies are already installed; there is no network access.
