# Kestrel MQ — Product overview

Kestrel MQ is a fully managed message queue for teams that want zero operations work.

## Delivery guarantees
Kestrel supports exactly-once delivery through transactional consumers: a message is removed from the queue only when the consumer's transaction commits.

## Regions
Kestrel runs in three regions: us-east, eu-central (Frankfurt) and ap-south. Data never leaves the region you choose.

## Throughput
A single Kestrel queue sustains up to 20,000 messages per second.
